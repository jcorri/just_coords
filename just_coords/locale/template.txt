# Help command
List of the just_coords commands:=
/coords  → Show this list=
/coords-mode1 → Hide coordinates=
/coords-mode2 → Show Position only=
/coords-mode3 → Show Position + Direction=
/coords-mode4 → Show Position + Direction + Biome=
/coords-cyan → Set color to Cyan=
/coords-magenta → Set color to Magenta=
/coords-red → Set color to Red=
/coords-white → Set color to White=
/coords-yellow → Set color to Yellow=
/coords-normal → Set font size to Normal=
/coords-big → Set font size to Big=
/coords-biggest → Set font size to Biggest=
/coords-top → Set display position to Top=
/coords-middle → Set display position to Middle=
/coords-bottom → Set display position to Bottom=
